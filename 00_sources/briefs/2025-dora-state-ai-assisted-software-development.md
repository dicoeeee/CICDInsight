# 2025 DORA State of AI-assisted Software Development

## 来源

- 标题：2025 DORA Report: State of AI-assisted Software Development
- 组织或项目：Google Cloud DORA
- 发布日期：2025-09-23
- 链接：[DORA Report](https://dora.dev/research/2025/dora-report/)、[发布解读](https://cloud.google.com/blog/products/ai-machine-learning/announcing-the-2025-dora-report)
- 来源类型：原始行业研究
- 能力状态：研究；当前报告修订版为 2025.2

## 一句话结论

DORA 发现 AI 采用与交付吞吐和产品表现的关系已经转正，但仍与交付稳定性下降相关，说明局部生成提速正在把压力转移到测试、审核和部署控制系统。

## 可核验事实

- 报告基于近 5,000 名技术专业人士的调查和超过 100 小时的定性数据。
- 2025 数据中 AI 采用与交付吞吐和产品表现呈正向关系。
- AI 采用继续与交付稳定性呈负向关系。
- 报告将 AI 定义为现有团队和系统能力的放大器。
- 提出的关键条件包括内部平台质量、清晰工作流、Value Stream Management、自动化测试、版本控制和快速反馈。

## CI/CD 相关性

- 涉及阶段：跨全部阶段，重点是系统吞吐与稳定性。
- 工具类别：工程效能、组织能力和价值流度量。
- 自主等级：覆盖 L0—L4 的环境条件。
- 涉及角色：CTO、研发效能、平台工程、开发团队和质量负责人。

## 对洞察的价值

这是主报告解释“为什么 Agent 投资必须同时改造平台、流程和人员能力”的核心证据。

## 限制与待验证项

- 研究对象是广义 AI 辅助开发，并未专门隔离 Agentic CI/CD。
- 调查研究的统计关系不能直接证明某个 Agent 产品的因果效果。

## 可引用判断

- AI 提高代码和变更吞吐后，如果测试、审核、部署和恢复能力没有同步增强，交付稳定性风险会被放大。
