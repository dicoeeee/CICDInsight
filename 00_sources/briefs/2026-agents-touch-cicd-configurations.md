# When AI Agents Touch CI/CD Configurations

## 来源

- 标题：When AI Agents Touch CI/CD Configurations: Frequency and Success
- 发布日期：2026-01-24
- 链接：[arXiv:2601.17413](https://arxiv.org/abs/2601.17413)
- 来源类型：原始实证研究预印本
- 能力状态：研究

## 一句话结论

实证数据显示软件 Agent 已经能够修改 CI/CD 配置，但这类变更占比仍低，说明“编码 Agent 会自然扩展为 CI/CD Agent”尚不是普遍现实。

## 可核验事实

- 研究报告 CI/CD 配置文件约占 Agent 变更的 3.25%。
- 不同 Agent 的占比存在差异，摘要给出 Devin 4.83%、Codex 2.01%。
- 变更主要集中于 GitHub Actions。
- 论文摘要称这类配置变更的可靠性与普通代码变更相当。

## CI/CD 相关性

- 涉及阶段：流水线配置、构建和部署自动化。
- 工具类别：软件 Agent、CI/CD Configuration 和实证度量。
- 自主等级：L2—L3。
- 涉及角色：开发者、CI 管理员、平台工程师和 Agent 治理人员。

## 对洞察的价值

它为市场宣传提供现实基线：Agent 接触 CI/CD 的频率仍明显低于普通代码任务，应区分潜在能力和大规模使用行为。

## 限制与待验证项

- 当前为预印本，需要核验数据集、成功定义和样本偏差。
- 配置变更可靠不代表部署结果或生产风险相同。

## 可引用判断

- 截至 2026 年初，通用软件 Agent 修改 CI/CD 配置仍是少数场景，真正的交付 Agent 需要更专门的上下文和治理。
