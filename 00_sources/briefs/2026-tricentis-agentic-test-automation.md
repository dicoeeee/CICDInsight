# Tricentis Agentic Test Automation

## 来源

- 标题：Introducing the latest Agentic Test Automation
- 组织或项目：Tricentis
- 发布日期：2026-02-16
- 链接：[Tricentis Blog](https://www.tricentis.com/blog/agentic-test-automation)
- 来源类型：官方产品博客
- 能力状态：Tosca 产品能力更新

## 一句话结论

Tricentis 让 Agent 从自然语言生成可执行的端到端测试，并复用既有测试资产和确定性自动化引擎，表现出“Agent 负责设计，成熟测试引擎负责执行”的混合架构。

## 可核验事实

- Agentic Test Automation 可从自然语言生成完整、可执行的 E2E Test Case。
- 支持 SAP GUI、SAP Fiori 和通用 Web 应用。
- Agent 使用 Tosca TBox 执行测试。
- Agent 会分析 Workspace 现有资产并复用、合并模块，减少重复。
- 可与 AI Workspace 结合管理和治理测试 Agent。

## CI/CD 相关性

- 涉及阶段：自动化测试和质量门禁。
- 工具类别：测试生成、测试执行、测试资产复用和 Agent 治理。
- 自主等级：L1—L3。
- 涉及角色：QA、测试自动化工程师、业务测试人员和质量负责人。

## 对洞察的价值

它说明测试 Agent 的成熟路径不是完全抛弃既有自动化，而是把 Agent 的规划与适配能力连接到稳定执行引擎和可复用测试资产。

## 限制与待验证项

- 85% 手工工作减少和 60% 生产率提升为厂商材料中的数据，缺少公开实验细节。
- 复杂业务断言和测试 Oracle 的可靠性仍需案例验证。

## 可引用判断

- 测试领域最现实的 Agent 架构，是让 Agent 生成和维护测试意图，由成熟执行引擎提供可重复验证。
