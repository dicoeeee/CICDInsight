# CLI 专题实验计划

本轮完成案头研究和实验设计，尚未在企业样本仓运行，因此不把计划结果写成事实。

| 实验 | 对照 | 核心指标 | 验证目的 |
|---|---|---|---|
| L1：人类输出 vs JSON 输出 | 同一 CLI 两种输出 | 解析失败、错误动作、Token、耗时 | 量化结构化输出价值 |
| L2：直接 CLI vs CLI+Skill | 同一任务集 | 首次成功率、无效调用、上下文量 | 量化知识包对接口使用的影响 |
| L3：直接 CLI vs MCP Wrapper | 同一能力和权限 | 接入工时、延迟、Token、审计完整率 | 判断协议层的真实收益和成本 |
| L4：共享身份 vs 任务身份 | 模拟部署任务 | 越权拦截、归因完整率、凭据暴露 | 验证身份与审计边界 |

推荐任务集覆盖：查询 PR 状态、归因 CI 失败、生成构建证据、执行 IaC Plan、查询制品签名和发布后只读调查。所有写任务默认限定在临时环境或 Draft PR。
