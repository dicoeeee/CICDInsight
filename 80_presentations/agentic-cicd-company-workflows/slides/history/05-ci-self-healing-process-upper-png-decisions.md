# CI 自愈流程图上半区 PNG 决策历史

## 2026-08-05：初始横向单排提案（已被替代）

- 提案：横向 `1600 × 480`，六个主节点单排从左到右，最多两个下方例外出口。
- 用户反馈：流程图只能占据 PPT 右边的上半部分，需要调整排版；颜色、字体和字号应符合 skill 要求。
- 处理：改为 `1200 × 640` 的 `3 + 3` 双排蛇形结构，并将 Microsoft YaHei、Arial、黑红灰配色和最小字号写入视觉约束。

## 2026-08-05：核心判断讨论（按用户要求暂停）

- 提案：以“先分流，再在授权范围内修复并验证，通过后才提交到 PR 分支”作为核心判断。
- 用户反馈：先不用考虑主题，直接把图画出来。
- 处理：将主题和候选标题从当前决策移出，直接按源图六阶段生成可视化草图；可见文字仍保持在已核验证据边界内。

## 2026-08-05：单向六步草图被否定

- 草图：六个节点采用 `3 + 3` 蛇形排列，按收集、分流、范围、修复、条件、提交依次呈现。
- 用户反馈：图显得简单，也没有 loop 概念；需要仔细分析 Nx Self-Healing 的真实机制。
- 处理：重新核对 Nx Source Brief、Deep Dive、研究证据和既有页面契约，确认应区分 Flaky 的恢复重跑、候选变更对原失败 Task 的定向复验、写回后的 PR CI 外层复验；新版改为三层控制流与两个反馈环，并明确不存在已证实的无限自动修复循环。
